# 开源方案借鉴与许可证

本 Skill 采用“方法借鉴、独立实现”，不复制第三方代码或界面素材。

- [Resume Matcher](https://github.com/srbhr/Resume-Matcher)（Apache-2.0）：借鉴主简历工作流、事实约束、职位定制与面试准备一体化。
- [Resuml](https://github.com/phoinixi/resuml)（ISC）：借鉴确定性评分、岗位族/细分方向、结构化 JSON/YAML 与 HTML/PDF 输出。
- [JobSync](https://github.com/Gsync/jobsync)（MIT）：借鉴结构化分数、Markdown 报告与提示词评测断言。
- [ResumeHQ](https://github.com/jananthan30/Resume-Builder)（MIT）：借鉴 ATS 与人工阅读双视角；未采用学校/公司声望、跳槽次数或 F-pattern 等偏置性启发式。
- [OpenResume](https://github.com/xitanggg/open-resume)（AGPL-3.0）：借鉴浏览器本地解析和隐私优先思路。
- [JSON Resume](https://jsonresume.org/)、[O*NET](https://www.onetcenter.org/)、[ESCO](https://esco.ec.europa.eu/)：作为结构化字段和职业能力词汇表的参考入口。

视觉参考为 [Cindy 下载页](https://cindy.cn/download/)：只提取深黑/米白/红色的色彩关系、工业编辑式排版、网格、细边框和切角卡片等通用设计语言；不使用其 Logo、品牌文案、字体文件或插画。

使用或发布本 Skill 时应保留本说明，并分别遵守上游项目许可证。当前脚本和模板为本项目独立实现。
