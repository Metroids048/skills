# Money OS

Route monetization work **before** jumping into implementation. Prefer this pipeline over inventing a complex tech product first.

## Pipeline

```
想法
  → dbs / dbs-diagnosis / dbs-benchmark / dbs-goal   # 值不值得做
  → business-model-canvas / startup-context / monetizing-innovation / positioning-canvas
  → jobs-to-be-done / opportunity-solution-trees / mvp-scoping / prd-writer / feature-prioritization-assistant
  → customer-research / review-mining / user-research-synthesis / product-discovery
  → copywriting / pricing / launch / directory-submissions / seo-audit / content-strategy
  → cold-outreach / cold-email / prospecting / sales-script / discovery-caller / proposal-generation
  → product-launch-manager / pmf-survey
  → (then) Code / vibe coding for MVP
```

## When → Which skill

| Intent | Skills |
|--------|--------|
| Unclear if idea is worth building | `dbs`, `dbs-diagnosis`, `dbs-benchmark`, `dbs-goal` |
| Save / resume diagnosis | `dbs-save`, `dbs-restore` |
| Business model / canvas | `business-model-canvas`, `startup-context`, `monetizing-innovation`, `positioning-canvas` |
| Split MVP / PRD / prioritize | `mvp-scoping`, `prd-writer`, `feature-prioritization-assistant`, `jobs-to-be-done`, `opportunity-solution-trees` |
| User pain / research | `customer-research`, `review-mining`, `user-research-synthesis`, `product-discovery` |
| Find first customers | `prospecting`, `cold-outreach`, `cold-email`, `sales-script`, `discovery-caller`, `proposal-generation` |
| SEO / content / launch | `seo-audit`, `content-strategy`, `copywriting`, `launch`, `directory-submissions` |
| Pricing / PMF | `pricing`, `pmf-survey`, `product-launch-manager` |

## Operating rules

1. If the task is about making money or validating a product idea, **load this skill first**, then the stage skill.
2. Do **not** start a large build until diagnosis + MVP scope are explicit (or the user explicitly says skip validation).
3. Prefer AI tool / thin SaaS / productized service over complex platforms.
4. After a diagnosis conclusion, suggest `dbs-save`. Next session: `dbs-restore` or continue last diagnosis.
5. When unsure which stage: open `dbs` (dbskill router) or ask one clarifying question.

## Fit for this founder

Strengths: AI product / LLM-RAG-Agent / vibe coding / growing commercial judgment.
Default paths: AI tools entrepreneurship, or productized outsourcing to overseas SaaS / custom.
