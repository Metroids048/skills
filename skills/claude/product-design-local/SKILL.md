# Product Design Local

Use local skills such as `product-discovery`, `web-prototype`, `design-taste-frontend`, `image-to-code`, and `visual-qa`. Start with user problem, audience, constraints, and acceptance evidence; produce information architecture, interaction states, visual direction, and an implementation-ready handoff. Do not rely on a hosted namespace, plugin cache, or Figma/UX Pilot OAuth. If source assets require an app login, mark that portion `APP_AUTH_REQUIRED`.
