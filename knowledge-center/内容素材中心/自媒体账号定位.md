# 6. 自媒体账号知识库

## 6.1 当前核心困难

- `[CONFIRMED]` 用户没有做过自媒体。
- `[CONFIRMED]` 完全不知道最终应该做一个什么样的账号。
- `[CONFIRMED]` 认为太专业太技术的不会做，太基础的竞争大，自己没有明显专家标签、资源标签或流量标签。
- `[CONFIRMED]` 对“施工队、实验室、造物记”等名字不满意。
- `[OPEN]` 账号名称尚未确定。
- `[CONFIRMED]` 简介方向整体可接受。

## 6.2 推荐账号定位

> 普通 AI 产品经理的 Agent 实战与验收记录。

更完整版本：

> 一个不会传统编程的 AI 产品经理，把 Codex、Claude Code 和 Cursor 放进真实复杂项目中，公开记录目标、执行、失败、修复、验收、成本和阶段结果。

### 不需要扮演

AI 专家、程序员导师、量化大师、自媒体导师、创业成功者或“照做就能赚钱”的营销角色。

### 核心承诺

> 帮观众看清 Agent 到底能做什么、哪里会翻车，以及怎样把它推进到真正可用。

## 6.3 目标观众

- 已经知道 AI 很强，但不会落地的人；
- 产品经理、运营、项目经理；
- 不会传统编程但想做工具的人；
- 使用 Cursor、Codex、Claude Code，但项目总做不完的人；
- 想做 Vibe Coding、副业工具和自动化项目的人；
- 想了解 Agent 工作方法而不想钻研底层模型的人。

## 6.4 内容难度

低理解门槛、高项目真实性、中等知识密度。

不讲 Transformer、模型训练、深度代码实现和纯基础按钮教学。重点讲目标、工作流、决策、问题、证据、验收、成本和阶段结果。

## 6.5 内容比例

- 50% 大众 Agent 问题；
- 30% 真实项目；
- 20% 工具和 Skills 实测。

工具内容固定视角：不复述功能，放进真实任务里验收。

## 6.6 长期栏目

- 《Agent 说完成以后》
- 《项目为什么没跑通》
- 《本周 AI 项目翻车报告》
- 《不会代码怎么验收》
- 《7×24 自动化实验》
- 《Alpha 工厂重构日记》
- 《这个 Skill 真能用吗》
- 《一个产品经理怎样指挥 Agent》
- 《真实项目切片》
- 《从需求到交付》

## 6.7 前 12 条验证内容

1. Agent 说任务已经完成，我为什么不相信？
2. 自动交易系统为什么一直不开单？
3. 视频系统测试通过，真实素材为什么仍可能翻车？
4. Codex 改了十几次，问题为什么越来越多？
5. 非程序员怎么验收 AI 写的项目？
6. 我怎样限制 Agent 不要无限重构？
7. Codex 和 Claude Code 怎么分工？
8. 一个复杂任务应该怎么拆给 Agent？
9. HyperFrames 做短视频到底行不行？
10. 我装了多个视频 Skills，真正留下几个？
11. GitHub 热门项目，普通人能不能跑通？
12. Codex 自动剪辑能替代剪映多少工作？

## 6.8 每条视频的固定叙事

1. 我想做什么；
2. 出现了什么具体问题；
3. 展示真实证据；
4. 原因是什么；
5. 当前解决到哪一步；
6. 哪些仍未解决；
7. 下一集验证什么。
