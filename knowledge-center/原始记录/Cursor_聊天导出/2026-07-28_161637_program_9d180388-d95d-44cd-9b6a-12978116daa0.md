## 方式一：前后端一起启动（完整服务）

需要两个终端，都在项目根目录 `c:\Users\win\Desktop\program` 下操作。

### 1. 启动后端（终端 1）

```powershell
cd .\aoqin-ai-demo-app\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

验证：

- 健康检查：http://127.0.0.1:8000/api/health  
- API 文档：http://127.0.0.1:8000/docs  

### 2. 启动前端（终端 2）

```powershell
cd .\aoqin-ai-demo-app\frontend
npm install
npm run dev
```

浏览器打开：**http://127.0.0.1:5173**

常用入口：

- `/login` — 登录（可选业务用户/专家/管理员）
- `/` — 工作台
- `/agents` — 智能体广场

## 使用方法

在 `aoqin-ai-demo-app` 目录执行：

```powershell
python start_all.py
```

脚本会依次：检测 Python / npm → 创建/复用虚拟环境 → 安装依赖 → 处理端口占用 → 启动后端与前端 → 打开登录页。按 **Ctrl+C** 会同时停止前后端。

## 已覆盖的情况与处理

| 情况 | 处理方式 |
|------|----------|
| 未安装 Python / 版本过低 | 提示安装路径，建议 `winget install Python.Python.3.12` |
| Windows 商店 Python 占位 | 自动跳过，改用真实安装 |
| 无全局 npm | 自动使用 `.tools/node-v24.14.0-win-x64` |
| 虚拟环境不存在 | 自动 `python -m venv` |
| 依赖未安装 | 自动 `pip install` / `npm install` |
| 端口 8000 / 5173 被占用 | 默认换用下一空闲端口；`--kill-ports` 可强制释放 |
| 仅要前端演示 | `--frontend-only` + 本地 Mock |
| pip / npm 网络失败 | 输出清华 / npmmirror 镜像设置提示 |
| 子进程异常退出 | 按前后端给出排查建议 |
| 后端非 8000 端口 | 警告 Vite 代理仍指向 8000，建议 `--kill-ports` |

## 常用参数

```powershell
python start_all.py --kill-ports      # 先释放占用端口
python start_all.py --skip-install    # 跳过依赖安装（二次启动更快）
python start_all.py --frontend-only   # 只起前端
python start_all.py --no-browser      # 不自动开浏览器
python start_all.py --force-mock      # 强制前端 Mock，不依赖后端
```

**说明：** 若之前已手动启动过服务，建议先关掉旧终端，或执行 `python start_all.py --kill-ports`，避免端口冲突。
