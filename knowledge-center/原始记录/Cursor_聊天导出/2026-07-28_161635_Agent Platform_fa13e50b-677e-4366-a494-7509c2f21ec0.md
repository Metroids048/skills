Assistant: ## 问题 1：创建后配置区空白 — 根因与修复

你提了 3 次，之前改的方向不对，真正的问题有两个：

**根因 A — 配置区依赖 JS 动态注入**
`05-agent-detail.html` 里 `#opsEditorRoot` 是空 div，内容要靠 `EditorShell.mount()` 注入。脚本一旦报错或加载失败，页面就是一片空白。

**根因 B — 创建时 ID 不一致**
`04-create-modal.html` 里 `configPageUrl()` 每次调用都 `Date.now()` 生成新 ID：
- `onAgentCreated()` 写入 sessionStorage 的是 ID **A**
- 倒计时跳转用的是 ID **B**
- `isFirstConfig()` 失效 → 扩展 Tab（基本信息/运行数据/版本与发布）没被隐藏

**本次修复：**
1. 三列编辑器（提示词 / 编排 / 测试）**直接写进 HTML**，不依赖 JS 注入
2. 创建流程使用 **`pendingAgentId` 只生成一次**，创建、跳转、存储用同一 ID
3. `<head>` 里同步脚本：`?new=1` 时**首屏即隐藏**扩展 Tab 和 v1/状态标签
