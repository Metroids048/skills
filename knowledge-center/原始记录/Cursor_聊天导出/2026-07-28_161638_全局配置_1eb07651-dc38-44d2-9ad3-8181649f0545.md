## 最可能的原因

Claude Code 改完前端后，Vite 会重做依赖预构建。启动日志里就有：

`Re-optimizing dependencies because vite config has changed`

这时浏览器常会：

- 拿到空的 `#app` 壳子（标题仍是 `frontend-demo`）
- 控制台出现 `Outdated Optimize Dep` / 模块加载失败
- 看起来像「什么都没有」

另外，一键启动时如果浏览器开得偏早，或旧标签页缓存了过期的依赖，也会出现同样的白屏。
