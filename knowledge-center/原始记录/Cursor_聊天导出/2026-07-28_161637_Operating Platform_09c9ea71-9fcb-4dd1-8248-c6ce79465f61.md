## 2. 如何让 Cursor「全部自动同意 / 最大权限」？

要分清 **Cursor Agent（本对话里的 AI）** 和 **Claude Code（终端/扩展）**，两套权限是分开的。

1. 按 **`Ctrl+Shift+J`** 打开 **Cursor 设置**（不是 VS Code 的 `Ctrl+,`）
2. 进入 **Agents**：
   - **Auto-run**：开启，让终端命令自动执行  
   - 在允许列表里写宽一点，例如：
     ```
     测试、构建、lint、mkdir/cp/mv、npm/pnpm install、git status/diff/log 均可自动执行。
     禁止 rm -rf、git push --force、删库、发布包。
     ```
   - 若有 **MCP 自动运行**，也一并打开（新版本才有）
3. **文件修改**：
   - 想**每次先审查再接受**：打开 **Applying Changes → Inline Diffs**
   - 想**尽量不弹确认、直接改文件**：关闭 Inline Diffs（部分版本会接近「自动保留修改」）

说明：Cursor **没有**一个官方「一键无限权限」开关；Auto-run 主要管**终端命令**，MCP 和文件改动仍可能单独要确认。

### B. Claude Code 扩展（在 Cursor 里用 Claude Code 面板时）

在 **用户设置** `%APPDATA%\Cursor\User\settings.json` 可增加：

```json
{
  "claudeCode.initialPermissionMode": "bypassPermissions",
  "claudeCode.allowDangerouslySkipPermissions": true
}
```

或在 Claude Code 会话里用 **`Shift+Tab`** 切换到 **Bypass permissions** 模式（扩展支持时）。

### C. Claude Code 终端 CLI（你现在的 `claude` 命令）

在 `~/.claude/settings.json` 里可加：

```json
{
  "permissions": {
    "defaultMode": "bypassPermissions"

}
```

或启动时：

```powershell
claude --dangerously-skip-permissions
```

也可用 **`dontAsk`** 模式（比 bypass 稍保守，仍会少很多确认）。
