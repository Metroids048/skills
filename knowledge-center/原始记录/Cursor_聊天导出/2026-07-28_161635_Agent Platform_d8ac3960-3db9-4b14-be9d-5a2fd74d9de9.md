## 建议的 0→1 Vibe Coding 流程（手动或写进 rule）

新开一个 **0→1 会话**时，不要直接说「帮我实现」，而是固定四段：

```
Phase 0 — 约束（自动）

Phase 1 — 设计（必须人工触发词）
  「用 brainstorming，先出 2–3 套架构方案，我确认后再写代码」

Phase 2 — 规划
  「用 writing-plans / planning-with-files-zh，写 task_plan + 模块边界 + ADR 草稿」

Phase 3 — 实现
  按 plan 分步做；大任务用 ouro-loop

Phase 4 — 交付
  ai-delivery-gate + verify-all
```

**关键句模板**（可直接复制）：

> 「这是 0→1 新模块，必须先走 brainstorming + writing-plans，输出架构图和模块职责，我 approve 之前不要写代码。」
