## 可以安全清理的（按收益排序）

### 立即可做（风险低）

1. **清空下载文件夹里的安装包** → 预计释放 **~4–5 GB**  
   驱动、Cursor、飞书、Figma 的 `.exe` 装完后可以删。

2. **Chrome 清缓存**  
   设置 → 隐私 → 清除浏览数据 → 选“缓存的图片和文件” → 预计 **~6 GB**。

3. **飞书清缓存**  
   飞书设置 → 通用 → 存储空间 / 清理缓存 → 预计 **~3–4 GB**。

4. **清临时文件**  
   `Win + R` → 输入 `%temp%` → 全选删除；再运行 **`cleanmgr`** 选 C 盘 → 预计 **1–3 GB**。

5. **开启存储感知**  
   设置 → 系统 → 存储 → 打开“存储感知”，自动清临时文件和回收站。

### 需要管理员权限（收益大）

6. **关闭休眠**（不用“休眠”功能的话）→ 释放 **6.3 GB**  
   管理员 PowerShell：
   ```powershell
   powercfg /hibernate off
   ```

7. **Windows 更新缓存 + 组件清理** → 预计 **2–5 GB**  
   管理员 CMD：
   ```cmd
   DISM /online /Cleanup-Image /StartComponentCleanup
   ```

8. **清理旧版驱动**（DriverStore 8.3 GB 里有很多旧版）  
   可用“磁盘清理”→ 勾选“设备驱动程序包”，或第三方工具 **Driver Store Explorer**。
