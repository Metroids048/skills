## 可行方案（按推荐顺序）

### 方案 1：cc-switch 供应商 + Anthropic 兼容网关（最省事）

很多中转站提供 **Anthropic 兼容端点**，网关按模型名路由到 GPT。

在 cc-switch 里 **添加供应商 → Claude Code**：

| 字段 | 示例 |
|------|------|
| 请求地址 | `https://api.ofox.ai/anthropic`（或你已有的 `https://ai.hctopup.com/anthropic`） |
| API 格式 | **Anthropic Messages (原生)** |
| API Key | 对应平台的 Key |
| 模型配置 | `gpt-5.5` 或 `openai/gpt-5.5`（以网关文档为准） |

四层模型建议都填同一个 GPT 模型名：

```
ANTHROPIC_MODEL = gpt-5.5
ANTHROPIC_DEFAULT_SONNET_MODEL = gpt-5.5
ANTHROPIC_DEFAULT_OPUS_MODEL = gpt-5.5
ANTHROPIC_DEFAULT_HAIKU_MODEL = gpt-5.5
```

然后点 **「使用/Enable」**，再跑你已有的同步脚本：

```powershell
powershell -NoProfile -File "$env:USERPROFILE\.claude\scripts\cc-sync-all.ps1"
```

验证：新开终端 → `claude` → 输入 `/status`，确认 `BASE_URL` 和模型已切换。

### 方案 2：cc-switch 本地路由（Proxy/Routing）+ 格式转换

cc-switch 3.9+ 自带 **本地路由服务**（默认 `127.0.0.1:15721`），支持：

- Anthropic ↔ OpenAI 协议转换  
- 热切换供应商（不用重启 Claude Code）  
- 故障转移、用量统计  

步骤：

1. cc-switch → **Settings → Advanced → Routing Service**  
2. **启动路由** → 打开 **Claude Routing**  
3. 添加支持 GPT-5.5 的供应商（OpenAI 兼容或带路由的中转）  
4. 在主界面选中该供应商并启用  

启用后 cc-switch 会把 `ANTHROPIC_BASE_URL` 改成本地代理（类似你现在的 18789，但是 cc-switch 自己的 15721）。

> 注意：你现在的 `18789` 是独立的 DeepSeek 专用脚本，和 cc-switch 内置路由是两套东西，切 GPT 时不要用 DeepSeek 那条链路。

### 方案 3：cc-router 做路由层 + cc-switch 管配置

如果你用 [cc-router](https://ccrouter.app/)，它提供虚拟模型槽位：

| cc-router 别名 | 用途 |
|----------------|------|
| `gpt-5.5` | 高推理（对应 opus 槽） |
| `gpt-5.4` | 日常 |
| `gpt-5.4-mini` | 轻量 |


cc-router 负责 Anthropic→OpenAI 转换和模型分发，cc-switch 负责一键切换。

## 关于「cc-switch 的 API」

cc-switch **桌面版没有对外公开的 REST 切换 API**，主要是：

| 方式 | 说明 |
|------|------|
| GUI / 托盘 | 点「Enable」切换，Claude Code 可热生效 |
| SQLite | 配置在 `~/.cc-switch/cc-switch.db` |
| 你的 `cc-sync-all.ps1` | 已从 DB 读 provider 并写入 `settings.json` |
| cc-switch-web | 无头/SSH 场景，浏览器 `http://localhost:17666` |
| 本地代理 | `127.0.0.1:15721` 接收 CLI 请求，不是用来「远程调 cc-switch」 |

程序化切换可以这样：

```powershell
# 1. 在 cc-switch GUI 里切到 GPT provider，或改 currentProviderClaude
# 2. 跑同步
powershell -NoProfile -File "$env:USERPROFILE\.claude\scripts\cc-sync-all.ps1" -ClaudeProviderId "<provider-uuid>"

# 3. 新开终端
claude
# /status 确认
```
