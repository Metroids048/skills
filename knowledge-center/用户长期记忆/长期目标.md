# 3. 长期目标

## 3.1 事业与收入目标

- `[CONFIRMED]` 在不影响主业的前提下建立可持续副业。
- `[CONFIRMED]` 优先探索自动化、数字产品和可复用工作流。
- `[CONFIRMED]` 希望通过 Agent 把过去需要技术团队完成的复杂任务产品化。
- `[OPEN]` 找到真正适合用户的长期变现方式，而不是追逐短期 AI 热点。

## 3.2 技术与 Agent 目标

- `[CONFIRMED]` 建立一套 Cursor、Codex、Claude Code 可共同使用的规则、Skills、项目记忆和验收体系。
- `[CONFIRMED]` 将 Prompt 升级成有目标、状态、证据、测试、停止条件和持久化输出的 Loop。
- `[OPEN]` 建立跨 Agent 的个人知识库和项目总账，本文件即第一版。

## 3.3 自媒体目标

- `[CONFIRMED]` 主要平台为抖音和小红书。
- `[CONFIRMED]` 用户没有自媒体经验，不知道最终应做成何种账号。
- `[CONFIRMED]` 用户不适合深度模型原理和硬核代码教学、极基础 AI 按钮教程、单纯 AI 新闻搬运、假装量化大神或 AI 创业成功者。
- `[INFERRED]` 最适合的账号模型是：

> 一个普通 AI 产品经理，把 Agent 放入真实复杂项目中，公开记录目标、执行、失败、修复、验收、成本和阶段结果。
