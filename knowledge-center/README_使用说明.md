# Cursor 全局知识管理中心 V1

本包包含：

1. `Cursor全局知识管理中心_架构与权限方案.md`
2. `交给Cursor的全局知识管理中心搭建总Prompt.md`
3. `各项目记忆与同步规则模板.md`

## 推荐执行

1. 把此前知识库文件与本包放入一个新的私有目录。
2. 在 Cursor 中只打开该中央目录。
3. 把“总 Prompt”交给 Cursor。
4. 先完成模块 0 和项目根目录确认。
5. 不要一次授予整个系统盘权限。
6. 项目注册表确认后，再逐项目安装。
7. 先用 3 个 fixture 项目验收，再处理真实项目。

## 关键原则

- 全局采集器：读全项目，写知识区，不写源码。
- 项目开发器：写当前项目，不写其他项目。
- CLI 任务可以高完整度记录。
- GUI 聊天需要结束归档；特别重要的完整聊天使用内置导出。
- Hooks 记录文件和命令，不承担完整聊天采集。
- 原始记录与长期摘要分离。
- 中央知识库只在私有环境保存。
