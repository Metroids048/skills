# 各项目记忆与同步规则模板

## 一、需要安装到每个项目的托管规则

### `AGENTS.md` 托管区块

```markdown
<!-- AI-KNOWLEDGE-MANAGED-START -->

## 共享用户记忆与项目知识

开始涉及本项目的非简单任务前，读取：

- `项目知识库/项目总览.md`
- `项目知识库/当前状态.md`
- `项目知识库/目标与验收标准.md`
- `项目知识库/开放事项.md`
- 与当前任务有关的：
  - `项目知识库/决策记录.md`
  - `项目知识库/错误与根因.md`
  - `项目知识库/已验证解决方案.md`

默认使用收口模式：

- 锁定一个主要目标；
- 明确验收标准；
- 优先阻塞问题；
- 不进行无关重构；
- 运行真实验证；
- 完成后停止。

任务结束时：

1. 生成中文会话记录；
2. 更新本项目当前状态；
3. 记录用户纠正、决策、错误、根因、修复和验证；
4. 只将稳定信息提议写入长期记忆；
5. 将 PUBLIC_SAFE 内容提取为视频候选；
6. 调用项目知识同步；
7. 不记录密钥和私有思维过程。

中央知识库路径由 `项目知识库/同步配置.yaml` 提供。
不得直接重写中央主知识库，只能提交增量记录和待确认补丁。

<!-- AI-KNOWLEDGE-MANAGED-END -->
```

## 二、Cursor Rule 模板

文件：

```text
.cursor/rules/全局知识与会话归档.mdc
```

内容：

```markdown
---
description: 读取项目长期知识，并在有意义任务完成后生成会话记录和同步项目知识
alwaysApply: true
---

# 项目知识

开始非简单任务前读取：

@项目知识库/项目总览.md
@项目知识库/当前状态.md
@项目知识库/目标与验收标准.md
@项目知识库/开放事项.md

按相关性读取：

@项目知识库/决策记录.md
@项目知识库/错误与根因.md
@项目知识库/已验证解决方案.md
@项目知识库/用户反馈与纠正.md

# 行为

- 默认中文回复。
- 代码和命令保持原语言。
- 使用收口模式。
- 不无关重构。
- 不伪造验证。
- 不读取秘密。
- 不自动发布、部署、交易、付款。
- 不直接覆盖中央主知识库。

# 归档

有意义任务结束后：

1. 保存用户目标和用户纠正；
2. 保存 Agent 已执行动作；
3. 保存 Git diff、commit、命令和测试；
4. 保存实际验证证据；
5. 区分 COMPLETE / PARTIAL / BLOCKED；
6. 创建项目中文会话记录；
7. 更新当前状态；
8. 提取 PUBLIC_SAFE 内容候选；
9. 运行隐私检查；
10. 同步到中央管理端。
```

## 三、Cursor Commands 模板

### `.cursor/commands/开始任务记录.md`

```markdown
现在开始记录本次任务。

1. 读取项目知识库中的项目总览、当前状态、目标与验收标准和开放事项。
2. 生成唯一任务 ID。
3. 保存：
   - 当前时间；
   - 用户原始目标；
   - 当前 Git 分支、status 和最近 commit；
   - 当前项目状态；
   - 当前任务唯一目标；
   - 可观察验收标准；
   - 明确非目标；
   - 敏感级别。
4. 不修改业务文件。
5. 输出本次任务记录文件路径，然后继续用户任务。
```

### `.cursor/commands/结束并归档.md`

```markdown
现在结束业务开发，执行会话归档。

读取：

- 本次可见对话；
- 初始任务记录；
- Git status、diff、log；
- 实际修改文件；
- 实际命令和测试；
- 生成产物；
- 用户纠正和否定；
- 当前项目知识库。

生成：

- 中文会话记录；
- 用户输入摘要；
- AI输出摘要；
- 代码差异；
- 验证报告；
- 决策更新；
- 错误和根因更新；
- 已验证解决方案更新；
- 当前状态更新；
- 开放事项更新；
- PUBLIC_SAFE 视频候选；
- 中央同步包。

强制：

- 没有证据不能写 COMPLETE；
- 不记录私有思维过程；
- 不写密钥；
- 不自动重写中央主知识库；
- 冲突生成待确认报告；
- 完成后运行同步。
```

### `.cursor/commands/同步项目知识.md`

```markdown
运行项目知识同步。

先 dry-run，输出：

- 待同步到中央的文件；
- 待同步回项目的文件；
- 冲突；
- 敏感文件；
- 将被排除的文件。

确认没有秘密和业务源码后执行增量同步。

同步完成后输出：

- 新增；
- 更新；
- 跳过；
- 冲突；
- Hash；
- 同步时间；
- 中央镜像路径。
```

### `.cursor/commands/生成视频素材.md`

```markdown
从本项目知识库和最近会话中提取公开视频素材。

必须满足：

- 有真实目标；
- 有冲突；
- 有证据；
- 有用户判断；
- 有阶段结果；
- 普通观众能理解；
- 不泄露客户、身份、账号、密钥和交易秘密；
- 不构成投资建议；
- 不把未验证结果说成成功。

输出到：
项目知识库/内容素材.md

并同步到中央：
内容素材中心/视频选题总库.md
```

### `.cursor/commands/Token耗尽前收口.md`

```markdown
停止新增分析和非必要修改，立即安全收口。

1. 保存已完成文件。
2. 检查 Git status 和 diff。
3. 运行当前阶段最小必要验证。
4. 没有执行的检查标记未验证。
5. 创建 WIP commit；是否 push 按项目规则。
6. 生成会话记录。
7. 更新当前状态和开放事项。
8. 记录下次继续的第一条命令或文件入口。
9. 同步项目知识。
10. 不开始新任务。
```

## 四、项目同步配置模板

`项目知识库/同步配置.yaml`

```yaml
版本: 1

项目编号: "PRJ-XXX"
项目名称: "<中文项目名称>"
项目根目录: "<绝对路径>"
中央目录: "D:/AI全局管理中心"
中央镜像目录: "D:/AI全局管理中心/项目镜像/<中文项目名称>"

敏感级别: "PRIVATE"

同步:
  启用: true
  项目到中央: true
  中央到项目: true
  原始聊天: false
  原始事件: false
  会话摘要: true
  Git差异摘要: true
  视频素材: true

Git:
  提交项目知识库: false
  提交Cursor规则: true
  提交原始记录: false

排除:
  - ".env"
  - ".env.*"
  - "**/*.key"
  - "**/*.pem"
  - "**/*secret*"
  - "**/*credential*"
  - "node_modules/**"
  - ".venv/**"
  - "dist/**"
  - "build/**"
  - "输出/**"
  - "缓存/**"
```
