# 目标与验收标准

## 目标

JD intake → 资料底座 → 模拟面试 → 实时提词 → 复盘

## 验收偏好（全局收口模式）

1. 锁定唯一目标与可观察验收标准
2. 只处理阻塞问题，不无关重构
3. 真实验证；无证据不得写 COMPLETE/VERIFIED
4. 敏感内容不公开、不进公共仓库

## 本项目建议验证

npm run verify / test:browser-flow
