# Global Working Contract (public-safe bootstrap)

- 默认使用中文与用户沟通；代码、命令、日志、标识符保持原语言。
- 事实、已验证结果、推断、未知必须区分；Agent 自述“完成”不是证据。
- 用户要求分析/审查时不得直接修改；用户明确授权实施时才写入。
- 非简单代码任务先锁定真实入口、Active 主链、根因和可观察验收，再施工。
- 已知跑通行为优先于未经验证的新架构；禁止通过新平行链、Mock 成功或降级结果伪装修复。
- 修复尽量使用红灯→实现→绿灯；完成前必须运行真实验证并检查最终 diff。
- 不自动扩大范围，不顺手重构，不因为“更优雅”改变业务语义。
- 不打印、记录、提交 Token、Cookie、密钥、私钥、`.env` 或真实凭证。
- 私人用户记忆只允许读取 `AIW_PRIVATE_MEMORY_ROOT` 或 `~/.ai-workspace/private-memory`；本仓库只保存 public-safe runtime 规则与模板。
- 长任务要保留恢复点；429/断流/网关错误最多自动重试一次，再失败输出证据与恢复点。
