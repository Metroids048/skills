# UI Review

Use for any user-facing UI change.

## Check

- Hierarchy: can the user tell what matters first?
- Layout: no overlap, clipping, accidental nesting, or unstable dimensions.
- Typography: sizes match context; no viewport-scaled type.
- Color: semantic, accessible, not one-note.
- Components: states exist for loading, empty, error, disabled, success.
- Interaction: controls have expected affordance and feedback.
- Responsive: mobile and desktop are both coherent.
- Visual quality: not generic template output.

## Acceptance

The screen should look believable as a real product screenshot and support the core workflow without explanation text.
