# Code Review

Use before claiming implementation complete.

## Check

- Does the code implement the accepted scope only?
- Are module boundaries clear?
- Is state owned in one place?
- Are errors handled visibly?
- Are tests or verification appropriate to risk?
- Are there fake successes, placeholders, or silent fallbacks?

## Output Shape

- Findings first, ordered by severity.
- Then open questions.
- Then brief summary.
