# Pricing

Use this for pricing, plan comparison, quota, billing, and packaging pages.

## Rules

- Make the recommended plan obvious but not manipulative.
- Compare by user outcome, not internal feature names.
- Show quota, limits, and billing period clearly.
- Enterprise/contact sales must explain what differs.

## Checks

- Mobile comparison remains readable.
- CTA labels match the plan action.
- Edge cases are covered: current plan, downgrade, trial, expired payment.
