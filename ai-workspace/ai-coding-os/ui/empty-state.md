# Empty State

Use this whenever a page, list, search, upload, or AI result has no content.

## Rules

- Explain the state, not the feature.
- Offer one best next action.
- Avoid generic cheerleading copy.
- If data is still loading, do not show an empty state.
- If the user lacks permission, say so plainly.

## Pattern

- Title: what is missing.
- Body: why it is missing or what to do.
- Action: create, upload, connect, retry, or clear filter.
