# UI Theme

Use this before making visual decisions.

## Direction

Default taste: restrained product quality inspired by OpenAI, Linear, Vercel, Raycast, and Apple system clarity.

This does not mean copying their surfaces. It means:

- Quiet hierarchy.
- Sharp information design.
- Few decorative elements.
- High-quality spacing and typography.
- Useful motion.
- Strong empty, loading, error, and success states.

## Avoid

- Generic Tailwind or shadcn defaults presented as final design.
- Card grids with no hierarchy.
- Cards inside cards.
- One-note palettes dominated by purple, beige, dark slate, or brown.
- Gradient blobs, decorative orbs, and vague atmospheric hero art.
- Big marketing heroes for tools that should be usable immediately.

## Required Before Coding

- Pick product context: SaaS, CRM, AI workspace, data console, consumer, portfolio, or landing.
- Pick visual tone: quiet operational, premium editorial, technical console, or product-led marketing.
- Define primary action, secondary action, and next-step state.
