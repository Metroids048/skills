# Form

Use this for intake, settings, creation, checkout, profile, and configuration flows.

## Required States

- Empty.
- Partially filled.
- Validation error.
- Saving/loading.
- Success.
- Recoverable failure.

## Rules

- Group fields by user decision, not database model.
- Label fields in user language.
- Show helper text only when it reduces mistakes.
- Preserve user input after errors.
- Primary button says the action result.

## Checks

- Keyboard navigation works.
- Error messages identify the field and recovery.
- Mobile input and button sizes are usable.
