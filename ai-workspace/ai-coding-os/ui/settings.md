# Settings

Use this for account, workspace, integration, model, security, and notification configuration.

## Rules

- Settings are for durable preferences, not primary workflow.
- Destructive controls require confirmation.
- API keys, model providers, and integrations need clear connection state.
- Save behavior must be obvious: auto-save, explicit save, or staged changes.

## Checks

- Defaults are visible.
- Changes are reversible where possible.
- Validation prevents broken configuration.
- Sensitive values are masked.
