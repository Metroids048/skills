# Tables

Use this for lists, review queues, records, logs, transactions, and admin data.

## Rules

- Tables must answer a user question.
- Columns should support comparison or action.
- Default sort must reflect the user job.
- Row actions should be visible or consistently discoverable.
- Empty state should suggest how to create or find data.

## Required

- Loading state.
- Empty state.
- Error state.
- Pagination or virtual scroll plan when data can grow.
- Responsive strategy: columns collapse, rows become cards, or horizontal scroll is intentional.
