# Chart

Use this for metrics, analytics, trading, operations, finance, and performance views.

## Rules

- Start with the question the chart answers.
- Axes, units, time range, and source must be clear.
- Highlight anomalies and thresholds when they matter.
- Do not use chart decoration that obscures comparison.

## States

- Loading.
- No data.
- Partial data.
- Error.
- Stale data.

## Checks

- Colors remain distinguishable.
- Tooltip values are readable.
- Mobile layout preserves the main comparison.
