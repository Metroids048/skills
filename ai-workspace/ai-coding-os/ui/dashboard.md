# Dashboard

Use this for operational, SaaS, CRM, admin, analytics, and AI console pages.

## Principles

- Dense but calm.
- Prioritize scan, compare, filter, and act.
- Avoid oversized marketing composition.
- Show the current state, exceptions, and next action.

## Required Regions

- Global context: workspace, user, account, project, or environment.
- Primary work surface.
- Filters or segmentation.
- Key metrics with definitions.
- Recent activity or exceptions.
- Empty/error/loading states.

## Checks

- No decorative cards with no decision value.
- Tables and charts use the same visual language.
- Repeated actions are predictable.
- Mobile keeps primary action reachable.
