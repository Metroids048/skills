# Code Review Workflow

Use this for PR review, local diff review, or agent-generated implementation review.

## Priority

Findings first:

- Bugs.
- Behavioral regressions.
- Security or privacy risks.
- Missing validation.
- Missing tests.
- Maintainability risks.

## Rules

- Reference exact files and lines when available.
- Avoid style-only comments unless style affects correctness or consistency.
- If no issues are found, say so and note residual risk.
