# Release Workflow

Use this before shipping or handing off product/UI work.

## Steps

1. Re-read the accepted Mini Spec or task card.
2. Confirm in-scope items are complete.
3. Confirm out-of-scope items were not added.
4. Run local verification.
5. Run code review.
6. Run UI/product review when user-facing.
7. Record known risks.
8. Summarize completed, verified, and remaining risks.
