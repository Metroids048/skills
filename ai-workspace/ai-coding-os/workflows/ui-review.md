# UI Review Workflow

Use this when reviewing a screen, prototype, Figma implementation, landing page, dashboard, or product UI.

## Review Order

1. Product purpose.
2. Information hierarchy.
3. Layout and spacing.
4. Typography.
5. Color and contrast.
6. Components and states.
7. Interaction.
8. Responsive behavior.
9. Accessibility.
10. Visual distinctiveness.

## Output

Findings first, ordered by severity:

- P0 blocks the task.
- P1 likely breaks user success.
- P2 quality or maintainability issue.
- P3 polish.

Include exact screen, file, selector, or viewport when available.
