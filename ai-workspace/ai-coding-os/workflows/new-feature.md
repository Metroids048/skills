# New Feature Workflow

Use this for new product, page, UI, AI product, or cross-file work.

## Steps

1. Read project `AGENTS.md`, project memory, and relevant docs.
2. Build the Mini Spec from `product/requirement-analysis.md`.
3. Identify primary layer: product, IA, UI, or AI/data.
4. Produce product design: user flow, entry, data owner, success path.
5. Produce UI design: surface, states, responsive behavior, interactions.
6. Confirm architecture: module boundaries, state owner, API/schema impact.
7. Generate task list with verification after each stage.
8. Wait for user confirmation.
9. Implement.
10. Self-test.
11. Run code and UI review.
12. Summarize completed, verified, and risks.

## Default Verification

- Existing repo verify command.
- Targeted tests for changed behavior.
- UI responsive check when tooling allows.
- Manual acceptance path in plain language.
