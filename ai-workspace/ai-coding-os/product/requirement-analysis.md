# Requirement Analysis

Use this before product, page, or UI implementation.

## Required Inputs

- Goal: what outcome should change for the user.
- Audience: who uses it and in what situation.
- Version target: prototype, internal beta, MVP, or commercial.
- Primary layer: product mainline, IA, UI, or AI/data.
- In scope.
- Out of scope.
- Acceptance path: the user story that proves it works.

## Clarification Gate

Ask before implementation when:

- The request is broad: "optimize", "make it better", "do the whole page".
- The task changes product flow, navigation, saved data, or visible entry points.
- Existing PRD, ADR, code, or memory conflicts with the request.
- The UI direction is described only as "high-end", "clean", or "like OpenAI" without a page goal.
