# Information Architecture

Use this before adding pages, nav items, tabs, drawers, or major sections.

## Page Responsibility

Each page needs one sentence:

- What this page is for.
- What this page is not for.
- What data it owns or displays.
- Where the user came from.
- Where the user goes next.

## Navigation Rules

- Do not create duplicate entry points for the same job.
- Do not hide the primary workflow behind secondary navigation.
- Avoid dashboard sprawl: operational tools should prioritize scan, compare, filter, and act.
- Landing pages should reveal the actual product, place, object, state, or offer in the first viewport.

## IA Review

Before implementation, check:

- No page has overlapping ownership.
- No nav path breaks the main user story.
- Back and re-entry flows preserve context.
- Labels match user language, not implementation names.
