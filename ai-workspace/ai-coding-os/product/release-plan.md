# Release Plan

Use this before declaring a product/UI feature ready.

## Release Card

- Version target.
- Included user stories.
- Excluded user stories.
- Migration or compatibility notes.
- Verification commands.
- Manual acceptance path.
- Known risks.
- Follow-up backlog.

## Rules

- Prototype release can use mock data only if the UI says so or the context makes it explicit.
- MVP release must preserve the core user story end to end.
- Commercial release needs accessibility, performance, security, and error handling review.
